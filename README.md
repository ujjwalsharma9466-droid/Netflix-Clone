NetWatch - Netflix Clone Landing Page

NetWatch is a fully responsive front-end clone of the Netflix landing page, built from scratch using HTML5, CSS3, and JavaScript. It replicates the classic Netflix UI/UX including the hero section, feature spotlights with embedded looping preview videos, interactive FAQ accordions, and a comprehensive footer.

Features

Responsive Design: Adapts smoothly across desktops, tablets, and mobile devices using CSS media queries and flexbox/grid layouts.

Interactive FAQ Accordion: Expandable and collapsible questions with smooth transitions and animated icon rotation powered by JavaScript.

Embedded Feature Previews: Showcases streaming services, offline downloads, multi-device support, and kid-friendly profiles using looping HTML5 <video> elements.

Custom UI Styling: Styled with Google Fonts (Poppins) and dark mode aesthetics matching modern streaming platforms.

Tech Stack

HTML5 (Semantic structure)

CSS3 (Flexbox, CSS Grid, Media Queries, Custom Styling)

JavaScript (ES6+) (DOM manipulation for interactive FAQs)

Google Fonts (Poppins)

Project Structure

NetWatch/
│
├── index.html       # Main landing page HTML structure
├── style.css        # Complete styling and responsive media queries
└── script.js        # Interactive FAQ accordion functionality


How to Run the Project

Clone or download this repository to your local machine.

Ensure all three files (index.html, style.css, and script.js) are placed in the same directory.

Open index.html in any modern web browser (Google Chrome, Firefox, Microsoft Edge, etc.) or run it using a live server extension (like Live Server in VS Code).
